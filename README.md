# BF2 Log

Tracks weekly Battlefield 2 co-op game nights: which maps have been played, at what player count (3/4/5/6), what server size (16/32/64), how many bots, win/loss, and difficulty. Public visitors can view progress; only the admin can log new sessions.

We play the 2005 Battlefield 2 base game with the AIX2 bot mod, plus our own custom maps and our own mods built on top of AIX2. We play online together through BF2Hub.
